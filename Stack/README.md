# 📚 Stack

## Definition

A **Stack** is a linear data structure that follows the **LIFO (Last In, First Out)** principle. This means the last element inserted into the stack is the first one to be removed.

The two primary operations are:

- **Push** → Insert an element onto the top of the stack.
- **Pop** → Remove the top element from the stack.

Common operations also include:

- **Peek/Top** → View the top element without removing it.
- **isEmpty()** → Check whether the stack is empty.
