## Linked List

A **Linked List** is a linear data structure where each element, called a **node**, contains two parts:

- **Data** – Stores the value.
- **Next** – Stores the reference (pointer) to the next node.

Unlike arrays, linked list elements are **not stored in contiguous memory**. Nodes are connected using pointers, which allows efficient insertion and deletion without shifting elements.
